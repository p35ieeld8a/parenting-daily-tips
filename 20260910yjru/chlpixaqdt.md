# 四川省妇幼试管进周前需要检查的项目有哪些？

> 更新时间：2026-09-10 (UTC+8)

四川省妇幼试管进周前夫妻需要检查有很多很多，如女方需要做的检查有抽血检查、白带检查以及染色体检查等，男方需要做的检查有抽血检查、精液检查以及遗传检查等。一般来说，做这些检查的目的就是看夫妻是否具有做试管的指征，以及便于试管医生根据女性患者身体情况制定相应的促排卵方案，以提高试管助孕的成功率，所以大家在做这些检查的时候，一定要积极配合医生，才能提高检查结果的准确率。

## 四川省妇幼试管进周前夫妻检查项目

无论是国内进行试管婴儿还是国外进行，都需要做好进周前的检查工作，一方面是为了让医生了解身体健康状况，另方面就是为试管婴儿方案的制定提供依据。一般来说，选择在四川省妇幼做试管的夫妻来说，试管进周前夫妻需要检查的项目大致就如下：

1、女方检查项目

- 1. 白带检查：白带常规、支原体衣原体检查、TCT等；
- 2. 抗苗勒氏管激素（AMH）：主要是了解卵巢基础储备功能；
- 3. 其他：胸透、心电图、乳腺彩超、肝胆脾彩超(空腹)、B超、输卵管造影等；
- 4. 染色体检查：通过抽血检查染色体，判断是否存在影响染色体或基因的异常情况；
- 5.性激素检查：月经第2-3天的卵泡生成素FSH、黄体生产素LH、雌二醇E2、睾酮T、泌乳素PRL，月经第14-21天检查黄体期孕酮P，以了解卵巢内分泌状况和储备功能；
- 6. 抽血检查：基础内分泌、优生四项、肝功能、肾功能、血常规、血型、凝血四项、肝炎系列、梅毒、艾滋病、抗精子抗体、抗子宫内膜抗体、甲状腺功能等，该项项检查需空腹。

2、男方检查项目

- 1. 内分泌检查：生殖内分泌功能障碍影响男性的性功能和生殖功能；
- 2. 遗传检查：包括染色体核型分析、ABO血型和RH血型、地贫筛查；
- 3. 精液检查：即常规及畸形率、支原体衣原体等，一般需要进行2-3次，并且检查前需要禁欲5-7天；
- 4. 抽血检查：内分泌、优生四项、肝功能、肾功能、血常规、血型、凝血四项、肝炎系列、染色体、梅毒、艾滋病、抗精子抗体等，该项项检查需空腹。

以上就是我所了解的关于四川省妇幼试管进周前夫妻检查项目，仅供大家参考。在此需要提醒大家的是，女性在检查前一天要清洗会阴部，并且男女双方穿着适合穿脱的衣裤，以方便检查。
